# Seed2

Seed2는 종자검사 기준값을 빠르게 떠올리고 반복 연습하기 위한 브라우저 기반 숫자 기준값 훈련 앱입니다. 정적 HTML/CSS/JavaScript로 동작하며, 검사 문제를 선택해 풀고 실전 기록과 오답을 브라우저에 저장합니다.

## 실행 환경

- 정적 HTML/CSS/JavaScript SPA
- 별도 빌드 단계와 npm 의존성 없음
- 계정, 서버 데이터베이스, 백엔드, 클라우드 동기화 없음
- 설정·오답·기록은 브라우저의 `localStorage`에 저장

브라우저 보안 정책과 오디오 로딩을 고려해 `file://`로 직접 열기보다 정적 HTTP 서버를 사용합니다.

```powershell
python -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000/`을 엽니다.

## 주요 기능

홈 화면에서 다음 기능으로 들어갈 수 있습니다.

- **실전모드**: 전체 문제 범위에서 10개 정답을 완주하는 모드
- **연습모드**: 검사종류·채종단계·작물을 선택해 무제한으로 연습하는 모드
- **오답노트**: 저장된 오답을 확인하거나 오답만 연습하는 모드
- **설정**: BGM 음량, 효과음, 진동 설정

### 실전모드

실전모드는 전체 허용 문제에서 가중 랜덤으로 문제를 고릅니다. 룰렛이 시각적으로 회전하는 동안 실제 출제 문제는 먼저 선택되어 있으며, 사용자가 `STOP`을 눌렀을 때 검사종류·채종단계·작물·항목과 질문이 공개됩니다.

문제의 숫자 답을 입력해 채점하며, 정답 10개를 달성하면 종료됩니다. 결과에는 완료시간, 시도 횟수, 정답률, 오답 수, 최대 콤보가 표시되고 이번 판의 오답은 오답노트에 저장됩니다.

### 연습모드

검사종류, 채종단계, 작물을 각각 하나 이상 선택해야 시작할 수 있습니다. 채종단계 그룹은 다음 실제 데이터 범위에 연결됩니다.

- 원원종: 원원종·원원종포
- 원종: 원종·원종포
- 보급종: 보급종·보급종포·채종포 1세대

선택 범위 안에서 문제가 무제한 반복 출제됩니다. 별도 완료 화면은 없으며 홈 버튼으로 나갈 수 있습니다.

### 오답노트

각 플레이 모드에서 틀린 문제는 오답노트에 저장됩니다. 동일 문제는 중복 저장하지 않으며, 오답노트 화면에서 전체 목록을 삭제하거나 `오답만 연습`으로 별도 무한 연습을 시작할 수 있습니다.

오답연습에서 정답을 맞혀도 오답노트가 자동으로 삭제되지는 않습니다. 삭제는 사용자가 `전체 삭제`를 선택했을 때만 수행됩니다.

### 숫자 입력 규칙

허용되는 입력은 음수가 아닌 십진수입니다. 입력의 `%`, 쉼표, 앞뒤 공백은 정규화됩니다. 숫자값이 같으면 표현 방식이 달라도 같은 정답으로 인정합니다. 예를 들어 `14`와 `14.0`, `0.1`과 `0.10`은 같은 값입니다.

### 모바일과 데스크톱 입력

- 모바일 화면에서는 숫자·소수점·삭제를 제공하는 전용 숫자 키패드를 사용합니다.
- 데스크톱 화면에서는 입력창에 직접 입력하고 Enter로 STOP 또는 제출을 수행할 수 있습니다.
- 화면 크기가 바뀌면 현재 플레이 단계에 맞춰 입력 방식과 컨트롤이 동기화됩니다.

## 기록과 이어하기

진행 중인 실전모드는 자동 체크포인트로 저장됩니다. 홈에서 실전모드 안내를 다시 열면 진행된 정답 수와 플레이 시간이 표시되며, `이어하기` 또는 `새로 시작`을 선택할 수 있습니다. 이어하기는 저장된 문제와 현재 단계(룰렛·답안·feedback), 시도 수, 오답 수, 콤보를 복원합니다.

완료한 실전모드는 체크포인트가 종료 처리되어 다시 이어하기 대상으로 표시되지 않습니다. 새로고침 후에도 저장 가능한 진행 상태는 복원되지만, 카운트다운 중 상태는 저장 대상이 아닙니다.

## 최고기록과 콤보

완료 최고기록은 다음 순서로 비교합니다.

1. 더 짧은 완료시간
2. 완료시간이 같으면 더 적은 시도 횟수
3. 완전히 같으면 기존 기록 유지

정답을 연속으로 맞히면 콤보가 증가하고, 오답을 제출하면 콤보가 0으로 초기화됩니다. 최대 콤보는 실전 결과에 표시되며, 콤보 자체가 별도의 보너스 점수를 만들지는 않습니다.

## 접근성 및 반응형 대응

현재 구현에는 다음 대응이 포함되어 있습니다.

- 실제 모달의 dialog semantics와 제목 연결
- 모달 열 때 포커스 이동, Tab/Shift+Tab 포커스 트랩, Escape 닫기와 포커스 복원
- 질문·답안·feedback의 live region 및 상태 semantics
- 모바일 터치 타깃과 safe-area 대응
- 긴 한국어 문자열과 긴 숫자 항목의 줄바꿈·스크롤·overflow 대응
- 짧은 모바일 세로 화면과 모바일 landscape 레이아웃 대응
- `prefers-reduced-motion` 환경에서 장식 애니메이션과 전환 억제

이는 코드·semantic 테스트와 자동 검증을 기준으로 한 지원입니다. 실제 기기, 실제 스크린 리더, 브라우저 확대 환경에서는 별도 확인이 필요합니다.

## 설정과 오디오

설정에서 다음을 조절할 수 있습니다.

- BGM 음량: 0~5단계
- 효과음 켜기/끄기
- 진동 켜기/끄기

설정은 초안으로 편집되며 저장을 눌렀을 때만 커밋됩니다. 설정 창을 X, 배경, Escape로 닫으면 초안과 BGM 미리보기가 커밋된 값으로 되돌아갑니다.

BGM은 홈·실전·연습 화면에 따라 트랙이 바뀝니다. 백그라운드 전환 중에는 BGM이 일시정지되고 복귀하면 재개됩니다. 홈 BGM과 효과음은 초기 로딩 대상으로 유지하고, 실전·연습 BGM은 해당 모드 진입 의도 시점에 로드해 초기 오디오 preload 비용을 줄입니다.

## 저장 데이터

현재 앱이 사용하는 주요 `localStorage` 키는 다음과 같습니다.

- `seedTraining_v1_2_settings`: 설정
- `seedTraining_v1_2_wrongNotes`: 오답노트
- `seedTraining_v1_2_bestCompletion`: 실전 완료 최고기록
- `seedTraining_v1_2_inProgressCompletion`: 진행 중 실전 체크포인트

정상적인 기존 데이터는 가능한 한 보존하며, 저장 실패가 채점·다음 문제·결과 화면을 중단시키지 않도록 저장 경계를 방어합니다. 체크포인트는 소유 run을 확인해 다른 진행을 덮어쓰지 않도록 보호합니다.

## 개발 구조

- `index.html`: 홈, 모달, 플레이, 결과 화면과 오디오 요소
- `css/style.css`: 홈 이미지 스테이지, 플레이·결과 레이아웃, 반응형·접근성 스타일
- `js/data.js`: 문제 규칙과 문제 세트 생성
- `js/app.js`: 상태, 라우팅, 문제 선택, 채점, 저장, 오디오, 생명주기 처리
- `tests/storage-boundary.test.js`: 저장 경계와 게임 흐름·접근성·반응형·오디오 회귀 테스트
